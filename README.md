# Wave для Windows

Официальные общие сборки Wave. Создатель: **@piercedmyself**.

[Скачать последнюю версию](https://github.com/piercedmyself/wave-updates/releases/latest)

## Версия 1.1.3: разовый ручной переход

В 1.1.3 восстановлена плавность переключения экранов и оптимизирована отрисовка волны. Добавлены новые шрифты, темы и назначение глобальных клавиш.

Изменился ключ подписи релизов: с 1.1.1 или 1.1.2 нужно один раз скачать ZIP 1.1.3 вручную. После установки 1.1.3 следующие общие версии снова обновляются автоматически. Полностью закрой старую Wave через «Выйти» в трее перед запуском новой.

Распакуй ZIP в постоянную папку и запусти wave.exe. Не запускай приложение прямо из архива: Windows может распаковать его во временную папку.

После ручного перехода на1.1.3 общая версия сама скачивает обновления в фоне и применяет их при следующем запуске. Настройка находится в разделе «Обновления». Вход, профиль, плейлисты, история, оформление и настройки прокси сохраняются. Отключение автообновлений отменяет и автоматическую установку уже загруженного файла.

Для перехода с1.1.2 или более старой версии этот архив нужно скачать один раз. Полностью закрой прежнюю Wave через «Выйти» перед первым запуском.

В ZIP находится тот же EXE, который доступен отдельным файлом в релизе. Панель владельца не входит в общую версию. Личные сборки обновляются отдельно.

В этом репозитории только описание и общие релизы. Исходники остаются приватными. Обновлятор проверяет Ed25519-подпись и SHA256 файла; предыдущий EXE сохраняется рядом как wave.exe.previous.

Встроенные шрифты распространяются по SIL Open Font License. Все лицензии включены в ZIP и в приложение.

Автообновление получает только полноценные релизы, которые создатель разрешил распространять автоматически. Микрообновления публикуются отдельно для ручной установки и не становятся последней автоматической версией.
